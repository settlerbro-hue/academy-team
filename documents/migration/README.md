# Проверка переноса

`relocation-manifest.json` содержит относительный путь, размер и SHA-256 каждого из 5 429 исходных файлов. Контрольные суммы проверены после копирования на D и повторно для архивной копии в `D:\Academy-Team\archives\before-path-update`.

Пути в манифесте отражают прежнюю структуру. В рабочей структуре сайт перемещён из `outputs/rvb-academy` в `apps/web`; 63 вспомогательных файла обновлены для новых путей. Поэтому исходный манифест предназначен для проверки архива до изменений, а не для проверки изменяемой рабочей версии.

Брендбуки и барные пособия дополнительно скопированы из Downloads в `documents/brandbooks` и `documents/menu`. Исходные загрузки не удалялись. На диске C рабочие каталоги заменены ссылками на D; фактические файлы проекта и резервной копии находятся на D.
