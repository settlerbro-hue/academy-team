# Редактор курсов — 24 октября 2026

Откройте «Обучение» → «Редактировать курс» либо «Создать курс». В каждом занятии можно добавлять обложки, заголовки, текст с форматированием, списки, цветные советы, таблицы, изображения, ссылки, PDF и видео. Блоки можно копировать и перемещать; есть отмена и возврат изменений. Готовые структуры добавляют план смены, объяснение темы или чек-лист.

«Сохранить черновик» сохраняет работу в общей базе для продолжения с другого ПК. Локальное восстановление дополнительно защищает ввод на текущем устройстве. Сотрудники видят только опубликованную версию. «Опубликовать» применяет изменения; уведомление сотрудникам включается отдельно. При одновременном редактировании устаревшая версия не перезаписывает новые изменения.

Для изображения, PDF или видео выберите соответствующий блок и загрузите файл до 50 МБ. Файлы находятся в закрытом хранилище academy-course-media. Владелец редактирует все курсы; администратор — только свою область. Сотрудник получает файл только если опубликованный доступный курс действительно ссылается на него.
