# Меню по брендам и заведениям — 23.10.2026

Вкладка меню: Руки Вверх Бар / 90-е; внутри каждого бренда Бар / Кухня и выбор заведения. Для сотрудника по умолчанию открывается его заведение. Другие доступные меню можно изучать, отметки сохраняются отдельно от зачтённого прогресса.

В главную, профиль, рейтинг и статистику менеджера входит только опубликованное доступное меню своего заведения: общие позиции своего бренда и позиции конкретного ресторана. Позиции другого филиала того же бренда исключены. История отметок не удалялась. Существующие RLS и полномочия менеджера сохранены.
