# Email в кабинете владельца

В карточках команды владелец видит актуальный email аккаунта и может искать сотрудника по имени или email. Миграция `026_owner_team_emails.sql` добавляет строго ограниченный RPC: только активный владелец, только зарегистрированные в академии профили, только user_id/email. Адреса не копируются в публичную таблицу профилей, рейтинг или учебные данные.

Проверки: `node scripts/test-team-emails.cjs` и `scripts/test-team-emails.sql`. Проверены полный список для владельца, отказ всем остальным действующим профилям и анонимным посетителям. Локальный интерфейс показал email у всех шести профилей; поиск по адресу работает без учёта регистра.

## Обновление askacademy.ru

На момент проверки 27 октября 2026 года домен обслуживается отдельным VPS `80.64.31.169` (HTTP server Caddy). Файлы интерфейса совпадали с версией 66. Учётные записи и материалы используют прежний Supabase. Автоматическое развёртывание из GitHub не подтверждено; SSH-конфигурации и ключей для этого сервера в текущем рабочем окружении нет.

Миграция уже применена к общей базе. Для отображения email на домене нужно развернуть результат `node apps/web/build-secure.cjs` (папка `apps/web/out`) существующим способом обновления VPS. Не загружать `dist`, исходные документы, SQL, файлы окружения или ключи в публичную папку веб-сервера. Не перезаписывать действующий `auth-config.js` на домене: в нём могут быть собственные настройки возврата после входа.

Новое отображение включено в портале Sites; отдельный VPS автоматически этим не обновляется. Выдача прав управляющих ожидает выбора аккаунтов владельцем после просмотра их почты.
