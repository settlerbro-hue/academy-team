# Красочные описания кухни — 23.10.2026

Из «Начитка_Кухня_Красочное_описание_блюд.pdf» перенесены описания 52 актуальных блюд РВБ. В карточке кухни добавлена закрытая по умолчанию панель «Красочное описание»; краткое «О блюде» остаётся видимым. Поле vividDescription редактируется в существующей форме меню владельцем и менеджером кухни своего заведения через academy_save_menu. Права не расширялись.

Обновление базы добавляет только отсутствующее поле payload.vividDescription и не затрагивает остальные поля и личные отметки. В JSON-выгрузки для развёртывания также добавлены описания. Новое содержимое не включается в публичную сборку сайта.

В PDF есть восемь блюд, отсутствующих в актуальном меню: «И рыбку съесть…», «Но я тебе не дам», «Танцуй! Танцуй!», «Круэлла — страчателла», «Я сочиняю рамен», «Запеканка Челентано», «Ночной дожор», «Нас и тут неплохо кормят…». Их описания не присваивались другим блюдам. Служебный раздел «Соусы» не является красочным описанием блюда и не импортирован. Для остальных позиций без описаний панель не выводится. Дубликат заголовка «В Багдаде всё спокойно» под «Сам ты — Наташа» исключён как редакционный повтор; тексты привязаны по содержимому. Опечатка названия «Импротозамещение» сопоставлена с «Импортозамещение началось…»; отличающийся порядок слов «Вам лишь бы» сопоставлен с «Вам бы лишь».

Проверки: в базе 52 заполненных поля; маршруты, область прогресса, импорт кухни и публичная сборка проходят; интерфейс на 390 px показывает свёрнутую и раскрытую панели, поле в редакторе и сохранение через текущий защищённый RPC.
