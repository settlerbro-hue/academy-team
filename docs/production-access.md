# Рабочие аккаунты академии

Supabase ivlinbwuudxyjaikwaoo хранит реальные аккаунты, роли, учебный каталог и результаты. Локальный прототип сохранён в apps/web/dist; рабочая сборка — apps/web/secure-dist, публикация — apps/web/out. Старые файлы с ответами тестов в публикацию не входят.

Владелец: подтверждённый аккаунт settlerbro@gmail.com. Новая регистрация через Google или email заполняет анкету и создаёт заявку pending. Учебные материалы доступны после подтверждения менеджером или владельцем. Выбор должности «Руководитель» не выдаёт административную роль.

Сотрудник читает доступные материалы, сохраняет личный прогресс и отметки меню. Менеджер видит сотрудников своего заведения и подразделения, одобряет заявки и проверяет письменные задания. Только владелец назначает менеджеров. Общие материалы редактирует владелец; менеджер создаёт материалы в своей области доступа.

Ключи тестов находятся в academy_private. Сервер сохраняет снимок теста и ключей при начале попытки; браузер передаёт только ответы. Повторная отправка не меняет результат. Просроченные попытки не засчитываются и исключены из рейтинга. Повторные попытки не увеличивают рейтинг искусственно.

Файлы хранятся в private bucket academy-assets. Активные участники получают временные ссылки. Публичный URL хранилища недоступен. Загрузка разрешена владельцу. Не помещайте service_role, secret key или пароль базы в публичную конфигурацию.

SQL миграции и проверки: apps/web/supabase. Проверки создают временные фикстуры и откатывают их; демонстрационные сотрудники в рабочую базу не импортируются. Не запускайте seed повторно поверх отредактированного каталога без отдельной резервной копии — он обновляет исходные позиции.

Для сборки: node apps/web/build-secure.cjs. Публикация через Sites workflow с текущим project_id. Включать общий доступ к странице входа следует только для защищённой сборки out.
