# Заявки, рабочие данные и название кабинета — 23.10.2026

Роль manager в интерфейсе называется «Администратор», роль admin — «Владелец». Внутренние идентификаторы и маршруты сохранены. Должность «Администратор» в подразделении «Зал» не выдаёт права автоматически.

В профиле сотрудника есть отдельная форма выбора заведения, подразделения и должности. Отправка создаёт заявку без изменения текущих прав. Одновременно допускается одна заявка; её можно отменить. Виден статус последних шести заявок, есть обновление статуса. Подтверждение/отклонение находится в кабинете администратора принимающего заведения и подразделения либо владельца. Самоподтверждение запрещено. Заявки администраторов видны для согласования только владельцу.

В редакторе сотрудника добавлена отдельная форма рабочих данных. Администратор может напрямую менять должность, подразделение и заведение только сотрудников своей текущей команды (employee); владельцу доступны все профили. Перевод не меняет role или status, не удаляет историю обучения. После перевода прежняя команда теряет серверный доступ, новый доступ следует из актуального профиля. Кэш команды очищается при смене области профиля. Подтверждение проверяет исходные данные и отклоняет устаревшие заявки. Прямое изменение отменяет незавершённые заявки.

Миграция 011_work_changes.sql применена после отдельного подтверждения владельца. Таблица закрыта для прямого чтения и записи; заявки доступны только через функции с явной проверкой полномочий. Операции записываются в аудит.

Исправлены внутренние отступы панели «Красочное описание»: специфичный селектор переопределяет компактный сброс padding у details, маркер панели находится внутри отступов, текст имеет собственные вертикальные интервалы.

Проверено: маршруты, область прогресса, импорт кухни, защищённая сборка. Два SQL-сценария под authenticated прошли: отправка, подтверждение, прямой перевод, сохранение роли, дубликаты, самоподтверждение, чужая команда, отклонение, отмена, запрет прямых записей и анонимного вызова. Все изменения тестовых профилей и заявки откачены. В браузере проверены редактор рабочих данных, зависимый список должностей и панель блюда на мобильной ширине.
