# Бар РВБ: программа обучения

Программа для барменов, барбэков, старших барменов и бар-менеджера РВБ Минск. Оба уровня подготовки сохраняют доступ к материалам для повторения.

1. **Добро пожаловать в команду — 90-е и Руки Вверх Бар.** Общий welcome-курс `welcome-90`; прежние занятия, тест и история обучения сохранены.
2. **Правила сотрудника.** Общий курс `guru-43403`, включая существующий тест «Правила сотрудника РВБ». Переименование сохраняет идентификаторы и результаты.
3. **Пособие бармена и барбэка РВБ — обучение.** `rvb-bar-foundations`: все 15 разделов ранее загруженного пособия, отдельные занятия с редактируемыми блоками. Порядок: приход, открытие смены, работа на смене, закрытие, недельный и месячный чек-листы, касса, открытие и закрытие станции, пополнение, ковры, посуда, поставки, заготовки, хранение и маркировка.
4. **Ассортимент бара РВБ.** `rvb-bar-assortment`: восемь разделов с отдельными тестами — крепкий алкоголь и аперитивы, пиво, вино и игристое, коктейли, настойки, сеты, безалкогольные и горячие напитки. Материалы ассортимента сверены с действующими 175 карточками бара РВБ 27.10.2026. Вопросы по составам коктейлей основаны на ТТК, не на старых составах карточек.
5. **ТТК бара РВБ — коктейли осень.** `rvb-bar-techcards-course`: 39 рецептур и четыре проверочных теста, расположенных после соответствующих групп занятий. Источник: таблица «РВБ ТТК», вкладка **«Коктейли Осень»**, ID листа `844076848`. Используется основная рецептура на порцию из F/H/I, без подстановки расчётов партий полуфабрикатов. Количественные вопросы не создаются для строк с отличающимися значениями в G/H. Основная рецептура Long Island не заполнена: в уроки и тесты она не включена.
6. **Аттестация у бар-менеджера.** Используется существующая устная аттестация бара и её результат в профиле. Принимающий — бар-менеджер с правом оценивания своего заведения или владелец; самостоятельное выставление оценок не добавляется. Согласование сдачи — лично, автоматическая заявка не реализована. Правило присвоения уровня подготовки бармену не меняется; правило трёх аттестаций официанта сохраняется.

По новым курсам создано 12 тестов, 153 вопроса. Порог новых тестов — 80%, без ограничения времени. Вопросы и ответы редактируются существующим редактором; ключи хранятся только в `academy_private.test_keys`.

На странице обучения есть маршрут из шести этапов. Он отображается только для подразделения «Бар» РВБ Минск и перечисленных должностей. Статус курса учитывает все его занятия и все проверенные сданные тесты. Маршрут рекомендует порядок, но не блокирует повторение и просмотр следующих занятий. Категорийные фильтры и приоритеты сохраняются.

## Обновления содержимого

Однократное применение: `supabase/seed-rvb-bar-training.sql`. Файл не меняет политики доступа, не удаляет прогресс и не перезаписывает уже созданные новые курсы при повторном запуске. Новые записи ограничены `restaurant_id=minsk`, `department=Бар` существующими серверными правилами. ТТК РВБ добавлены отдельным материалом `rvb-bar-techcards`; существующая ссылка «90-е» сохранена.

Снимки источников и аудит вопросов находятся в `supabase/sources/rvb-*-20261027.json` и `rvb-bar-training-audit.json`. Они остаются в приватном репозитории и не попадают в публичный `out/`. Регенерация файлов: `node scripts/build-rvb-bar-training.cjs`. Не применять заново старые массовые импорты поверх отредактированных курсов.

Тестовые файлы: `scripts/test-rvb-bar-training.cjs`, `scripts/test-rvb-bar-training.sql`. Серверная проверка создаёт попытки только внутри транзакции с `ROLLBACK`.

Миграция `028_training_course_venue_scope.sql` исключает экзамен по ассортименту «90-е» (`guru-50011`) из обязательной программы РВБ. Его доступность для ознакомления не меняется. При выборе своей должности в РВБ он также скрыт из основной подборки; режим «Все должности» сохраняет просмотр.
