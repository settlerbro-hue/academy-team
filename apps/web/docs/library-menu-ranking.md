# Библиотека, новинки меню и рейтинг — 28 октября 2026

## Библиотека

В форме материала добавлен раздел «Доступ по подразделениям и должностям».
Ограничение выключено по умолчанию. Миграция не обновляет материалы и не меняет их нынешнюю доступность.
При включении требуются подразделение и хотя бы одна подходящая должность. Можно выбрать несколько подразделений и должностей в пределах полномочий редактора. Ограничение хранится в `payload.libraryAccess`; старые поля аудитории не переосмысливаются.

Сервер проверяет аудиторию при чтении материала, его готовых вложений и объектов приватного хранилища, а также при выборе получателей уведомления. Владелец, операционный директор и управляющие сохраняют существующий управленческий доступ; Админ подразделения может читать и редактировать собственные материалы даже для другой должности внутри команды. Область заведения, публикация и прежние специальные ограничения остаются обязательными.

## Меню

В редакторе карточки есть переключатель «Новинка» и дата/время окончания. Для новой карточки предлагаются 14 дней; существующие карточки автоматически новинками не становятся. В `payload` сохраняются `isNewItem` и `newBadgeUntil` (ISO timestamp).
Небольшая отметка появляется справа сверху и исчезает по таймеру без перезагрузки. Сервер отклоняет включённую отметку без корректной будущей даты.
