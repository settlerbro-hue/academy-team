# Обучение администратора РВБ

Семь этапов для должности «Администратор», подразделение «Зал», РВБ Минск:

1. Добро пожаловать в команду — общий курс двух брендов.
2. Правила сотрудника.
3. Стажировка менеджера — девять занятий, пять проверок для РВБ.
4. Управление персоналом — восемь занятий, семь проверок.
5. Меню кухни РВБ — 11 занятий и проверок.
6. Меню бара РВБ — восемь занятий и проверок.
7. Сводный список 33 проверок шести основных курсов в порядке занятий.

В пяти адаптированных проверках стажировки 36 вопросов. Неподтверждённые суммы, акции, депозиты, графики, лояльность и KPI другого бренда не выдаются за условия РВБ. Перед исходными уроками показано пояснение: актуальные условия нужно уточнять у управляющего. Оригиналы пяти тестов сохранены для «90-е» с прежней историей.

Приоритет курса управления персоналом для администратора РВБ — «Важно для начала работы». Остальным должностям и «90-е» сохранён исходный приоритет. Общие курсы меню сохраняют аудитории официанта и хостес. Другие существующие назначения администратора не удаляются; они не входят в сводный блок 33 проверок маршрута.

Должность администратора не выдаёт управленческие права. Маршрут не назначает роль и не вводит автоматическую аттестацию администратора. Предпросмотр владельца и операционного директора не использует личный прогресс другого сотрудника.
