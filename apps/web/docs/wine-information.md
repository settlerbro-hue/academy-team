# Информация о винах — 28 октября 2026

В действующей базе 51 карточка: 30 в общем меню «90-е», 21 в меню РВБ Минск. Полный перечень с источниками и заполненными описаниями: `supabase/wine-information-20261028.json`.

Восемь разделов: Вино; Страна, регион; Сахар; Виноград; Стилистика вина; Дегустационные характеристики; Гастрономия; Способ производства. При отсутствии подтверждённого техлиста последние четыре раздела дают типичный профиль сорта или стиля; технология прямо обозначена как типичная. Неизвестные сахар, регион и состав не выводятся из сорта. Противоречия версий обозначены в тексте. Например, Light House Alcohol Free не идентифицирует конкретный продукт; Tamari Мальбек Tarapaca в исходном меню смешивает названия. Наименование не исправляется без подтверждения.

Обогащение меняет только `payload.description` по точным ID. Цены, фото, доступ, названия, публикация и личные отметки не меняются. SQL проверяет исходные описания на конкурентные правки и равенство всех прочих полей до COMMIT. Повторное применение допустимо, если описание уже совпадает. Исходный снимок сохранён вне публичной сборки в `supabase/sources/wines-before-20261028.json`.

Клиент отображает восемь подписей жирным, каждую строку отдельно; произвольный HTML экранируется. Редактирование доступно в прежнем поле «Описание». Для структурированных винных описаний обходится старый очиститель учебных текстов: иначе он удалял строки с неопределённостью и склеивал переносы. Прежние описания остальных категорий обрабатываются как раньше. Список вин и их описания загружаются из защищённой базы, в публичную сборку не включаются.

Проверка: `node scripts/test-wine-information.cjs`, затем полный `check` и безопасная сборка. Перед применением SQL — та же транзакция с ROLLBACK; затем применение и повторное чтение 51 описания.
