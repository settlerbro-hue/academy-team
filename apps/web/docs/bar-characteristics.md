# Характеристики позиций бара

Обновлено 29.10.2026: 375 опубликованных карточек обоих брендов (51 вино, 125 алкогольных позиций, включая пиво, 96 коктейлей, 22 сета, 15 настоек, 44 безалкогольных напитка, включая пиво, 22 горячих напитка). Неопубликованная проверочная карточка исключена.

В «Подробнее» доступны редактируемые поля: страна / категория, стилистика, способ производства, дегустационные характеристики, позиционирование, гастрономия. Существующие поля приготовления и подачи сохраняются. Вино получает два дополнительных поля, ранее проверенные четыре поля не перезаписываются.

`supabase/bar-characteristics-20261029.json` — точечные дополнения по ID и источники. `menu:90` и `menu:rvb` обозначают исходный состав или название из соответствующего меню. Ссылки HTTPS ведут к производителям, владельцам брендов, официальным дистрибьюторам или источникам происхождения бренда. Само наличие ссылки не означает подтверждение всех деталей партии: ограничения указаны в тексте карточки.

Категорийные описания обозначены как «типичный профиль» или «ориентир». У коктейлей дегустационный профиль прогнозируется по составу, без назначения пропорций и приёмов приготовления. У настоек без рецептуры ориентир строится по названию, а общий метод не объявляется подтверждённой технологией бара. Гастрономия и позиционирование — редакционные рекомендации.

Не переносить сведения No. Ten на Tanqueray London Dry; не трактовать Zacapa 23 как минимальную выдержку 23 года. Не назначать Singleton 12 винокурню без бутылки. Для Beluga и лицензированных пивных марок отделять происхождение бренда от страны конкретного выпуска. Не считать «Белое Золото» пшеничным только по названию. Не переносить 100% agave с отдельной линейки Sierra на стандартную. Точные ABV, сахар и награды не добавлять без подтверждения выпуска.

Применение выполнено транзакцией с проверкой полного исходного payload каждой карточки. При конкурентном изменении любой карточки вся транзакция отклоняется. Обновляются только перечисленные поля; цены, фото, ингредиенты, объёмы, доступ и публикация не затрагиваются. Резервная копия исходных строк и контрольный результат сохраняются в рабочем каталоге задачи, не в публичной сборке.
