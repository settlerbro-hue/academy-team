# Общая база Академии

Порядок применения через SQL Editor проекта `ivlinbwuudxyjaikwaoo`:

1. `migrations/001_academy.sql` — таблицы, RLS, закрытые ключи, серверные функции, private Storage bucket.
2. `bootstrap-owner.sql` — отдельно подтверждаемое назначение владельца, проверяет UUID и подтверждённый email.
3. `seed-content.sql` — реальные материалы и тесты; демо-сотрудники и результаты не импортируются.
4. `tests/authorization.sql` — реальные проверки PostgreSQL под ролью authenticated; тестовые записи откатываются.

Нельзя размещать SQL с ключами ответов в статическом каталоге сайта. Каталог `supabase` находится вне публикуемого frontend. В браузере используется только publishable key.

Регистрация вызывает `academy_enroll`; роль всегда employee, статус pending. Только активный менеджер своей команды или администратор может подтвердить сотрудника. Менеджер ограничен заведением и подразделением; назначать роли может только администратор. Изменение анкеты сотрудником после подтверждения запрещено. Совпадение должности с названием руководящей роли прав не выдаёт.

RLS разрешает сотруднику читать собственные данные и опубликованные материалы; менеджеру — данные своей команды. Общие материалы редактирует администратор; менеджер может редактировать материалы, явно закреплённые за его заведением и подразделением. Ключи тестов и аудиторский журнал лежат в закрытой схеме.

`academy_start_test` сохраняет неизменяемый снимок задания и ключей. `academy_submit_test` считает результат на сервере, повторная отправка возвращает сохранённый результат. Просроченная попытка не считается сданной. Текстовые ответы ожидают ручной проверки через `academy_review_attempt`, баллы ограничены числом ручных вопросов. Пользователь не может редактировать баллы или статус попытки напрямую.

`academy_complete_lesson` проверяет принадлежность урока курсу; повторное завершение идемпотентно. `academy_set_mark` разрешает изменение личных отметок и отметок подчинённого сотрудника менеджером. Обе операции требуют активного аккаунта.

Private bucket `academy-assets`: чтение и выдача signed URL доступны только активным пользователям. Загрузка и обновление файлов — администратору. Само создание bucket не загружает файлы: загрузку и проверку ссылок необходимо завершить отдельно.

SQL-проверки не равны проверке OAuth и опубликованного интерфейса: полный вход, ожидание подтверждения, кабинет менеджера и доступ к файлам дополнительно проверяются в браузере. До применения SQL backend считается подготовленным, а не подключённым.
