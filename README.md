# Академия команды · 90-е и Руки Вверх Бар

Приватный проект сайта обучения сотрудников и кабинетов менеджеров четырёх заведений.

## Продолжить разработку на другом ПК

1. Войдите в GitHub под аккаунтом settlerbro-hue.
2. Склонируйте репозиторий или скачайте Code → Download ZIP и распакуйте.
3. Откройте папку проекта в Codex или редакторе. Нужен Node.js 22 или новее.
4. Выполните из корня: `npm run dev` (без npm: `node apps/web/scripts/preview.cjs`).
5. Откройте http://127.0.0.1:4173/ и войдите в свой аккаунт академии.

Установка зависимостей не требуется. Подробности: [DEVELOPMENT.md](apps/web/DEVELOPMENT.md).

## Структура

- apps/web/secure-dist — рабочий frontend, авторизация и защищённые кабинеты.
- apps/web/supabase — миграции, серверные проверки, исходные данные переноса.
- apps/web/dist — архив прототипа и исходные фото, документы и видео.
- documents — оригиналы брендбуков и меню.
- docs — описание архитектуры и результаты проверок.

## Проверка и публикация

`npm run check` проверяет синтаксис. `npm run build` формирует безопасный каталог out в корне. Публикуется только out; dist, documents, SQL и ключи тестов не должны попасть в публичную сборку. Project ID существующего сайта сохранён в .openai/hosting.json. Отправка изменений в GitHub не обновляет сайт автоматически — публикацию выполняйте через Sites workflow.

Рабочий сайт: https://rvb-academy-prototype.settlerbro.chatgpt.site/
База: Supabase ivlinbwuudxyjaikwaoo. Аккаунты, права, результаты и опубликованные файлы остаются в общей базе. Локальные изменения через интерфейс также затрагивают её. Для экспериментов со схемой используйте отдельный тестовый проект. Не запускайте seed и bootstrap повторно поверх рабочей базы без резервной копии и проверки.

Временные сессии, пароли, секретные ключи и кеши инструментов не переносятся. Эта копия не заменяет резервное копирование текущей базы и Storage.
